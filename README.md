# Writeups

A collection of cybersecurity challenge writeups, walkthroughs, notes, and lessons learned.

This repository contains writeups from platforms including:

- [Hackropole](https://hackropole.fr/)
- [TryHackMe](https://tryhackme.com/)
- [OverTheWire](https://overthewire.org/wargames/)
- [Hack The Box](https://www.hackthebox.com/)

## Purpose

This repository documents my learning progress through hands-on cybersecurity labs and capture-the-flag-style challenges. Each writeup focuses on the methodology, tools, commands, observations, and key takeaways used to solve the challenge.

> These writeups are intended for educational purposes and authorized lab environments only.
